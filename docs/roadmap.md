# Product Roadmap

Prioritas lintas versi: **performance > usability > visual > gimmick**. V1 harus selesai sebelum fitur versi berikutnya dikerjakan.

## V1

- 3D scene berbasis source GLB.
- Navigation melalui object interaction dan navbar fallback.
- About.
- Projects.
- Skills, termasuk Backend dan AI/CV.
- Education.
- Achievements dengan placeholder sampai data final tersedia.
- BMS / 3D visualization.
- Contact dengan placeholder sampai data final tersedia.
- Loading screen.
- Responsive dasar.
- WebGL fallback dan accessibility dasar.
- Performance optimization.
- Successful production build.

## V1.1

- Improved camera transitions.
- Configurable scenery.
- Project screenshots.
- Better mobile experience.

## V2

- Character animation.
- Interactive monitor.
- Day/night mode.
- Sound effects opsional.
- Easter eggs.
- Richer BMS interaction.

## Scope Rule

Fitur V1.1 dan V2 tidak boleh menghambat V1 selesai. Jangan membuat architecture, dependency, atau abstraction khusus untuk fitur tersebut sebelum ada kebutuhan implementasi nyata.
